Sitio web informativo e interactivo para el **Hotel Aguamansa**. La plataforma utiliza JavaScript para renderizar dinámicamente la información de habitaciones, servicios y comodidades consumiendo datos estructurados en archivos JSON locales.

---

### Características Principales

- **Carga Dinámica por JSON:** Generación interactiva del catálogo de habitaciones y servicios mediante manipulación del DOM con JavaScript.
- **Galería de Habitaciones:** Exposición visual detallada de las opciones de alojamiento y sus comodidades.
- **Sección de Contacto y Ubicación:** Información institucional y accesos directos de contacto.
- **Diseño Adaptativo (Responsive):** Interfaz fluida adaptable a dispositivos móviles, tablets y computadoras.

---

### Stack Tecnológico

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Manejo de Datos:** Archivos JSON locales
- **Framework CSS:** Bootstrap
